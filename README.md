# BIG BROWN DOG

**小白和棕色狗的蛋糕爭奪戰**

半夜，棕色狗偷吃了小白排了兩個小時才買到的草莓蛋糕，還抱著剩下的蛋糕逃跑了。小白一路追了過去……

七個章節，每一章都是不同類型的遊戲：跑酷、解謎、恐怖、射擊、3D 動作……
所有像素美術、音樂、音效都是用程式畫、用程式合成的。

## 下載

到 **[Releases](https://github.com/turtlepear/big-brown-dog/releases/latest)** 下載 `BIG_BROWN_DOG_v1.0.0.zip`，解壓縮後打開 `BigBrownDog.exe` 就可以玩，不用安裝。
第一次打開如果跳出「Windows 已保護您的電腦」：按「其他資訊」→「仍要執行」（這個 exe 沒有付費的數位簽章）。

- Windows 10／11（64 位元）
- 繁體中文／English
- 鍵盤、手把（Xbox／PlayStation／Switch）都可以

## 提醒

有恐怖、驚嚇的關卡（突然跳出來的畫面、尖叫聲），也有閃光和畫面震動，可以在「設定」裡調低或關掉。
